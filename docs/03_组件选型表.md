# 03 · 组件选型表

> 「这段文案该用哪个画面件？」—— 填 `storyboard.ts` 时对着这张表选。
> 配套：`06_填表说明.md`（怎么填）、`remotion/src/storyboard.ts`（类型定义源头）。

选型分两步：**先定版式（layout），再定件（block）**。

---

## 第一步 · 定版式（layout，5 选 1）

| layout | 结构 | 什么时候用 | 本片用例 |
|---|---|---|---|
| `band` | 上段文字卡 `888×450 @y440` + 下段画面卡 `888×480 @y900` | **一段话要「说理 + 配画面」两件事**，最常用 | s2 s3 s4 s6 s12 s17 |
| `tall` | 整高卡 `888×920 @y440` | 内容是一整块、不需要单独画面卡（清单、步骤、词表、对比） | s5 s7 s8 s9 s10 s11 s13–s16 s18 s20 s21 |
| `hook` | 顶带（居中）→ 缩窗后落两段式 | **只给首镜**。人物满幅时文字只能走顶带 | s1 |
| `fullcard` | 整幅 `1080×1920` 翻页 | 素材本身就是整幅设计稿（如自查卡片），塞进 888 宽会不可读 | s19 |
| `cta` | 顶带金底 | **只给末镜**。收尾 CTA | s22 |

判断口诀：
- 有「配图」的需求 → `band`
- 只是把一件事讲成一屏 → `tall`
- 首镜 / 末镜 → `hook` / `cta`

> ⚠️ `hook` 的顶带**只在缩窗点之前安全**（人物缩进右上圆窗后，居中顶带会压脸）。
> 所以 `hook` 必须配 `settleAt`（缩窗后落到两段式的时刻），见 s1。

## 第二步 · 定件（block，20 选 1）

### 文字类

| 内容形态 | 件 | 关键字段 | 本片用例 |
|---|---|---|---|
| 一句话，要逐字升起强调 | `rise` | `text` `size` `color` | 到处 |
| 3 个短词并列（药丸） | `chips` | `items` `gold`(第几个金底) | s1 s2 s3 s6 s9 s12 |
| 一行内两种样式（小标签 + 大值） | `inline` | `parts[]` | s2「通知里只有一句」+「不予推荐」 |

### 界面 / 设备类

| 内容形态 | 件 | 关键字段 | 本片用例 |
|---|---|---|---|
| 平台判定、系统提示（带 ! 圆标） | `notice` | `title` `body` `stamp`(右上红章) | s2 s6 |
| 电脑 / 界面 / AI 工具（带红绿灯的显示器框） | `monitor` | `title` `w` `screenH` `badge` `glow` `inner` | s3 s4 s12 |
| 真实照片铺满画面卡 | `photo` | `src` `caption` | s1 |

> `monitor.inner` 有两种：
> - `{t:'row', parts:[...]}` — 屏幕里横排内容。`parts` 里 `{text,size,color}` 是文字，
>   `{bar:190,kind:'mask'}` 是打码条（会随 `maskAt` 提亮）、`{bar:150,kind:'line'}` 是细占位条。
> - `{t:'text', text}` — 屏幕里就一行字。

| 内容形态 | 件 | 关键字段 | 本片用例 |
|---|---|---|---|
| 两行对比（同一框内，label → 说法） | `rowsbox` | `rows[{label,text,accent}]` | s5「我以为 / 平台读」 |

| 纵向分组容器 | `group` | `gap` `align` `blocks` | （需要混排时用） |

## 三条选型纪律（踩过坑的）

1. **中间必须是真画面，不是空面板。**
   涉及电脑 / 手机 / AI 工具 / 页面 / 步骤 / 数据 / 对比时，必须选 `monitor` / `notice` /
   `wordgrid` / `steps` / `checks` / `stat` 这类**有实体内容**的件。
   用一块空框或一行大字冒充画面 = 用户原话「这中间空的一大段空在这干嘛」。

2. **一个卡至少 3 个信息块。**
   文字卡只有标题会显得空。补齐法：标题 + 一句展开 + `chips` 一行。
   本片 22 镜全部满足（`tall` 卡的底边留 `160px` 内边距，否则最后一行被字幕压住）。

3. **不做「画面套画面」。**
   画面卡里只放内容本身，不要再嵌一层带边框的卡（用户原话「像套娃一样」）。

## 反面清单（别这么选）

| ❌ 错误选法 | ✅ 应该 |
|---|---|
| 讲「AI 帮我审核」却只放 `rise` 一行字 | `checks`（✓/× 清单），让人看见审核结果 |
| 讲「三个违禁词」却用 `chips` 药丸 | `wordgrid`（词格 + 金 ✗），药丸是「并列」不是「禁忌」 |
| 讲「平台判违规」却自己写一句话 | `notice`（平台口吻 + ! 圆标 + 红章） |
| 整幅设计稿硬塞进 `tall`（888 宽） | `fullcard` 整幅上屏（本片 s19 就是这么定的） |
| 所有镜都用 `tall` 图省事 | 按内容选；`band` 才是「说理 + 配画面」的主力 |
