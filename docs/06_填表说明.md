# 06 · 填表说明

> 换一条新视频，**只改 `remotion/src/storyboard.ts` 一个文件**。
> 版式骨架、组件实现、动效参数都在 `blocks.tsx` / `scene-from-config.tsx` 里，属于固定不变量。

---

## 0 · 心智模型

```
章娟的口播视频
   ↓ ① 提音轨
raw.wav
   ↓ ② CPU 字级时间戳（video-talkcraft）
timing.json   ← 每镜文本 + 每个字的时刻
   ↓ ③ 填表（本文件）
storyboard.ts ← 每镜说什么、用哪个件、锚在哪句词上
   ↓ ④ 渲染
成片
```

**只有 ③ 是每次要做的活，且它是填数据，不是写代码。**

---

## 1 · 前置：素材与文案

| 要什么 | 说明 |
|---|---|
| 口播视频 | 带人像的录屏即可，**不用另录音频**（提音轨） |
| 文案 | **数字与专有词必须人工核对**。ASR 最容易错数字，而锚点错一个字 → 静默失效 |
| 素材（可选） | 需要真实照片/视频的镜，去 Pexels 抓（方法见 `references/pexels-harvest.md`） |

> ⚠️ **文案不能省**。字级时间戳依赖准确文本。她问过「文案就不用再发了吧」——不行。

## 2 · 填 STORYBOARD（`storyboard.ts` 末尾）

### 2.1 每镜一条 `ShotConfig`

```ts
{
  id: 's5',              // 必须与 timing.json 的 scene id 一致
  layout: 'tall',        // 5 选 1，见 03_组件选型表.md
  at: '我以为这是在展示',  // 整卡进场时刻（锚点）
  body: [                // layout=tall 用 body；band/hook 用 top + media
    {t: 'rise', text: '我以为这叫真实', size: 70, color: 'cream', at: '我以为这是在展示'},
    {t: 'rowsbox', rows: [
      {label: '我以为', text: '展示我平时怎么做'},
      {label: '平台读', text: '在往站外引流推广', accent: true},
    ]},
    {t: 'rise', text: '同一件事 · 两种读法', size: 44, color: 'gold', at: ['挺真实的', 0.3]},
  ],
}
```

### 2.2 时间锚点 `At` 的三种写法

```ts
at: '一个字都没问题'          // ① 原话子串 —— 首选，跟着嘴走
at: 8.5                       // ② 镜内秒 —— 只在没有合适词时用（如缩窗点）
at: ['这事儿呢', 0.35]        // ③ 子串 + 偏移秒 —— 最常用（「这句话之后 0.35 秒」）
```

### 2.3 版式字段对照

| layout | 用哪些字段 |
|---|---|
| `band` | `top:{at,blocks}` + `media:{at,gap?,pad?,blocks}` |
| `tall` | `body: Block[]` |
| `hook` | `band:{text,size,at,outAt}` + `settleAt` + `top`/`media` |
| `fullcard` | `pages:[{src,at,outAt?,dir?}]` + `pill?` |
| `cta` | `band:{text,size,at,gold:true}` |

## 3 · 填 CAMERA（重音微动表）

每镜 1–4 拍。**落拍点 = 「这个字被念到」的时刻 + `off` 秒**。

```ts
s6: [
  {say: '推', off: 0.02, scale: 0.032, frames: 8, shake: 2},  // 「有引流推广的嫌」
],
```

| 字段 | 含义 |
|---|---|
| `say` | 本镜口播稿里的字/词，**取首次出现位置** |
| `off` | 字头之后几秒落拍，默认 0 |
| `scale` | 缩放增量，`0.024` ≈ 2.4%（常用 0.022–0.036） |
| `frames` | 回弹帧数，默认 6 |
| `shake` | 抖动幅度，默认 0（重音才给 1–2） |

**节奏规则**：不是每镜都要抖。一句话里挑 1 个重音字落拍即可；
列举型（s14 四个极限词、s15 四个承诺词）才逐项落拍。

## 4 · 铁律（每条都付出过返工）

1. **锚点必须是该镜文本的连续子串。**
   `tSay` 找不到就 `return 0`（**不报错**），元素会在第 0 帧提前冒出，很难发现。
   自查：`python3 scripts/anchor_audit.py <project>/remotion/src`。
   > ⚠️ 上屏文字 ≠ 锚点。锚点取**原话**（如「这事儿呢」），上屏文字可以是提炼（如「没人会主动告诉你」）。

2. **凡「带秒数」的参数，搬到新片必须重新推导，不能只抄数值。**
   本片 s1 踩过：`shrinkAt=8.3` 是给标准工程 **3.16s 的钩子**定的，
   本片钩子 **9.84s** 跨过缩窗点 → 顶带压脸。
   换片时对 `shrinkAt / expandAt / outAt / settleAt / 各段进场时刻` 都要问：
   **「这条在新时间轴上还成立吗？」**

3. **字幕只保留一层。**
   底部口播字幕之外，不能再放同一句/同一信息的字幕。
   中间可以有视觉标题，但必须服务于图形，不得当第二条字幕。

4. **中间必须是真画面**（见 03 的三条纪律）。

5. **优先复用已验收的件**；没有合适件时先用 CSS/SVG 做可读示意图，
   仍不足再从 Pexels 找素材。外部素材必须在预览中实际出现并避开人物与字幕。

6. **音频也要做连续性验收**：抽查片头、各中段、片尾的音频流与响度，
   确认人声 / BGM / 音效没在某个时间点断掉。**不能只看文件「有音轨」。**

## 5 · 执行步骤（每条视频固定走这 6 步）

1. **先列出「固定不变」和「本条要替换」的内容。**
   固定：人物位置 / 画面比例 / 中间素材区位置尺寸 / 字幕区 / 时间轴规则。
   替换：文案 / 锚点 / 素材 / 重音表。
2. **改完先渲关键帧预览，不直接渲染整条。**
3. **逐镜检查**：人物是否仍在右上固定位；中间素材是否出现在指定区域与时间段；
   是否被字幕或其他元素遮挡。
4. **任一项不符合 → 先修正并重新预览**，全通过再渲染。
5. **不能只凭「渲染成功」判断完成**，必须实际看预览帧。
6. **出片后跑自动验收**：逐镜量中段内容区的灰度标准差与边缘强度（抓「整镜没画面」），
   再查静音段、音轨长度、响度、真峰、削顶。报 ❌ 不许交付。

> 渲染命令与验收脚本见 `yaoyao-talkcraft` skill 的 `references/`。

## 6 · 一个测量陷阱（本片实测）

验收脚本量「中段内容区灰度 std」判空白时，**采样点必须在元素都进场之后**。
若采样落在镜头前段（只有标题已入、步骤条/列表还没到），量到的是纯背景，
会误报「中段疑似空白」——本片 s10/s13/s16/s20/s21 就被误报过一次。
**采样取每镜 70%–75% 处**比较稳。

同理，比 PSNR 时必须**同条件**：PNG 比 PNG。拿 PNG 去比 H.264 成片，
量到的是编码损失（30 多 dB），不是画面差异。
